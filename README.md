# Globe · 旅行照片地球仪

把保存在电脑上的旅行照片放到地球仪上浏览。照片中的 GPS 用来归类旅行地点；可以转动地球、切换城市，再打开该城市的照片。照片和位置数据保存在本机，不提交到 GitHub。

本分支 `pinch-toggle-v5` 在原版「深空制图仪」上加入了本地照片相册和三种操作状态：全球浏览、城市观察、照片相册。地球由 p5.js 绘制，浏览器内的 MediaPipe Hands 识别手部关键点；没有摄像头时也可以用鼠标和页面按钮操作。

## 在 macOS 上运行

```sh
git clone -b pinch-toggle-v5 https://github.com/Wencle-Sun/globe.git
cd globe
python3 server.py
```

打开 <http://127.0.0.1:8000/>，需要手势时允许浏览器使用摄像头。项目不需要 npm、账号或云服务。JPG、PNG 照片可以直接导入；导入 HEIC/HEIF 前，还需安装 `heif-convert`：

```sh
brew install libheif
```

**请使用 `python3 server.py`。** 原版安装方法中的 `python3 -m http.server 8000` 只能提供静态网页，不能读取或保存旅行照片。如果 8000 端口已被旧服务占用，先在运行旧服务的终端按 `Control + C`，再启动 `server.py`。

## 导入与浏览

1. 点击「添加照片」，选择 JPG、PNG、HEIC 或 HEIF 原图。单张照片上限为 40 MB。
2. 有 GPS 的照片会归入附近 80 公里内的已有城市；附近没有已有城市时以坐标标记。无 GPS 的照片进入「待归类」，可在页面上指定城市。照片归属也可以在相册中修改。
3. 右侧显示有照片的地点。点击城市按钮进入城市观察，再点「查看照片」打开相册。照片会从小到大展开；可用页面按钮、方向键和 `Esc` 浏览或返回。

| 状态 | 手势 | 页面操作 |
| --- | --- | --- |
| 全球浏览 | 单手摆动让地球惯性旋转；食指与拇指捏合、松开、再捏合，进入右侧提示的城市 | 鼠标拖动地球、滚轮缩放、点击城市按钮 |
| 城市观察 | 握拳左右摆动切换有照片的地点；停稳后张开手掌打开相册；双捏合返回全球 | 点击城市按钮、「查看照片」或「返回全球」 |
| 照片相册 | 张掌左右摆动翻页；握拳保持返回城市 | 上一张／下一张、方向键、`Esc` |

双捏合切换目前是**实验性操作**：只在一只手入镜时处理，第一次捏合会锁定目标并显示「再捏一次」，松开后须在 1.2 秒内再次捏合。当前识别代码还要求中指、无名指或小指至少一根伸开；其余三指都蜷起时，捏合可能不会被识别。照片相册中不处理双捏合。若手势不稳定，页面按钮可完成同样的模式切换。

## 遇到问题

- **页面显示「请用 python3 server.py 启动照片服务」**：当前打开的是静态服务器，`/api/photos` 不可用。停掉旧服务，按上面的命令运行 `server.py` 并刷新页面。右侧应显示照片数和地点数。
- **捏合后没有「再捏一次」提示**：先确认右侧有已归类的旅行地点，左侧显示「识别中 · 1 只手」，并让至少一根非食指的手指伸开。摄像头未就绪、两只手同时入镜或没有可进入的照片地点时，不会触发切换。
- **照片没有出现在城市里**：检查它是否在「待归类」；没有 GPS 的照片需要手动指定城市。80 公里自动归类只是初步结果，也可以手动修正。

## 本地数据与技术

`server.py` 只监听 `127.0.0.1:8000`。照片原件、浏览预览图和索引分别保存在 `local_photos/originals/`、`local_photos/images/`、`local_photos/photos.json`，整个 `local_photos/` 已被 Git 忽略。照片处理使用 macOS 的 Swift/ImageIO 和 `sips`；HEIC/HEIF 预览另外使用 `heif-convert`。城市匹配使用项目内的离线城市表，手部识别模型也随仓库提供。

当前版本不支持 Live Photo 视频、批量删除或云端同步。真实摄像头下的双捏合识别仍在调整。更详细的操作与版本说明见 [旅行相册文档](docs/TRAVEL_ALBUM.md)；原版地球仪说明见 [原版指南](docs/GUIDE.md)。

## 切换版本

先停止本地服务，再切换分支：`pinch-toggle-v5` 是当前旅行版，`glass-inertia-v4` 保留上一版双手切换操作，`main` 是原版地球仪。例如运行 `git switch glass-inertia-v4` 可以回退。切换分支不会删除被 Git 忽略的本地照片；返回旅行版后，仍需使用 `python3 server.py`。
