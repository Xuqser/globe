# 旅行地球仪手势测试单（gesture-debug-v6）

这份测试单用于区分摄像头识别、手势规则和照片服务的问题。当前流程是：

`全球浏览 (globe) → 城市观察 (city) → 照片相册 (album) → 城市观察 → 全球浏览`

一次只测一个动作。某项失败时，**先点「复制状态与事件」并保存文字，再刷新页面**；刷新会清空诊断记录并回到全球模式。调试面板只在网址带 `?debug=1` 时显示，不保存视频或照片。

## 准备

1. 在终端进入项目：`cd /Users/johnsonxu/globe`。运行 `git branch --show-current`，确认是 `gesture-debug-v6`；如果不是，运行 `git switch gesture-debug-v6`。
2. 用 `python3 server.py` 启动。若 8000 端口已被旧的 `python3 -m http.server` 占用，先到那个终端按 `Control + C`。
3. 打开 [本机调试页](http://127.0.0.1:8000/?debug=1)，在浏览器里允许摄像头。右侧应显示照片数和至少 1 个地点；诊断日志应出现「照片服务已加载」。
4. 让一只手完整地留在画面里，手掌朝向摄像头，先静止约 1 秒。诊断面板的「手数」应稳定为 `1`。测试期间先不要让第二只手入镜。

如果右侧写着「请用 python3 server.py 启动照片服务」，先修复服务；如果始终没有手部识别结果，先检查浏览器摄像头权限和左侧「手势」状态。此时继续测捏合不会有意义。

每次进入或退出一个模式后，先等约 1 秒再做下一个手势；代码有约 650–700 毫秒的切换保护时间。按钮操作不受这个等待限制。

## 分项测试

| 编号 | 起始状态 | 怎么做 | 预期结果 |
| --- | --- | --- | --- |
| A 页面按钮基线 | 全球 | 点击右侧任一有照片的城市 →「查看照片」→「返回城市」→「返回全球」 | 依次显示 `city → album → city → globe`。这一步不需要摄像头，先排除照片服务和页面切换的问题。 |
| B 全球旋转 | 全球；单手静止 | 向左或右**单方向**摆手一次，再慢慢把手收回 | 地球转动一次并逐渐减速；收手不应使它反向抽动。这是一次惯性拨动，不是实时跟手拖动。 |
| C 进入城市 | 全球；右侧有目标城市 | 食指与拇指捏合 → 明显分开 → 再捏合；其余三指至少伸开一根，手始终留在画面中 | 右侧先显示「再捏一次进入」，随后模式变为 `city`。日志依次出现「第 1 次捏合」「松开已确认」「第 2 次捏合：进入城市」。 |
| D 握拳切城市 | 城市；至少 2 个有照片地点 | 先保持握拳和静止约半秒，再向左或右移动一次 | 城市名称变化一次。每次切换后先停稳，再试下一次。 |
| E 张掌开照片 | 城市 | 重新握拳、静止约半秒，然后张开手掌并保持约半秒 | 模式变为 `album`，显示该城市的照片。切城动作后需要重新握拳，因为切城会清除上一次手势准备状态。 |
| F 张掌翻照片 | 照片；当前城市至少有 2 张 | 张掌静止约半秒，再向左或右移动一次 | 照片序号改变一张；到第一张或最后一张时不会越界。只有 1 张照片的城市跳过本项。 |
| G 握拳关照片 | 照片 | 握拳并保持至少半秒 | 相册关闭，回到 `city`。 |
| H 返回全球 | 城市；切换后先等约 1 秒 | 再做一次「捏合 → 分开 → 捏合」 | 日志出现第一次、松开和「第 2 次捏合：返回全球」，模式变为 `globe`。 |
| I 冲突检查 | 任意模式 | 让两只手同时入镜，再收回一只手 | 面板显示手数 `2` 时不应切换模式；回到一只手后会短暂等待约 6 帧。照片模式中的双捏合也不应切换模式。 |

测试 C、H 的两次**闭合**必须间隔 180–1200 毫秒。第一次闭合的判定值是「拇指/食指距离÷掌长」小于 `0.45` 且「其他三指有伸开」为「是」；松开需判定值大于 `0.58`（或其余三指都收起），并连续识别到 2 帧。做动作时可以用「合、开、合」的节奏，每一步略停顿；手离开画面**不算松开**。

全球摆手需要手心位置移动约画面宽度的 7.5% 才会触发；城市切换和照片翻页约为 6.5%。这些是程序阈值，不需要拿尺测量，只用来解释为什么很小的摆动没有反应。全球摆手后，回到起点附近并停稳，或把手移出画面再重新开始，才能测试下一次拨动。

## 失败时看什么

| 看到的情况 | 首先核对 |
| --- | --- |
| 手数一直是 `—` 或 `0` | 摄像头权限、左侧状态、手是否完整入镜。 |
| 手数频繁在 `1` 和 `2` 之间跳 | 第二只手或误检会暂停手势；先保持画面里只有一只手。 |
| 指尖已接近，但没有「第 1 次捏合」 | 看距离是否真的小于 `0.45`，以及「其他三指有伸开」是否为「是」。 |
| 有第 1 次捏合，却没有「松开已确认」 | 把指尖分得更开，保持至少两帧；松开期间不要把手移出画面。 |
| 有松开，但没有第 2 次捏合 | 检查日志是否写着「过快」或「超时」；第二次闭合也必须满足手型和距离阈值。 |
| 日志说「进入城市」但页面没切换 | 记录当前模式、右侧照片地点数和完整日志，这属于模式切换问题。 |
| 按钮能操作，手势不能操作 | 照片服务与界面基本正常，重点检查摄像头、关键点数值和手势时间门槛。 |

## 发给我用于分析的记录

每次先测 **C：进入城市**。失败后点「复制状态与事件」，把文字贴到聊天里；再补充下面几项即可：

```text
测试编号：C / D / E / F / G / H / I
浏览器与摄像头：
左侧「手势」状态：
实际动作与结果：
诊断面板复制的文字：
```

诊断文字可能包含手数、动作时间和照片/地点**数量**，不包含照片图像或具体坐标。无需发送原照片。收到记录后，我们再针对失败环节改阈值或状态逻辑。
