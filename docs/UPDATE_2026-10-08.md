# 2026-10-08 更新：手势与操作流程

当前版本：`axis-spin-city-fist-v10`。项目有三个模式：全球浏览 `globe`、城市观察 `city`、照片相册 `album`。页面按钮可完成同样的主要切换；摄像头手势仍需在真实环境中继续测试。

## 今天修正了什么

1. 加入 `?debug=1` 诊断面板和[分项测试单](GESTURE_TEST.md)。面板显示手数、手型、捏合比例与事件，可复制文字；不会记录摄像头画面或照片。
2. 捏合闭合需要连续 3 帧，减少横摆时单帧指尖重叠造成的误切换。
3. 全球旋转改为 ☝️ **只伸出食指、其余三指收起**，读取食指尖位置；🤏 **食指与拇指合—开—合、其余三指收起**用于切换全球和城市。捏合时手腕需基本静止。
4. 城市中张开整只手掌并保持约半秒即可打开照片；即使之前误记了第一次捏合，也不会阻断这个动作。
5. 全球模式的手势旋转只绕地轴：食指横向拨动控制经度，上下拨动不再把视角推向两极。横向触发位移从画面宽度约 7.5% 降到 5.5%，初速度和惯性均增加，让一次拨动转得更远。鼠标拖动仍可调整俯仰。
6. 修复了城市中握拳被误认为捏合后，横摆切城被跳过的问题。稳定握拳后的横移现在会参与切城判断，并在诊断事件里记录“握拳摆动，切换城市”。

## 从打开网站到浏览照片

1. 在项目目录运行 `python3 server.py`，打开 `http://127.0.0.1:8000/`，需要手势时允许摄像头。首次进入是**全球浏览**。
2. 点击「添加照片」导入本机照片。有 GPS 的照片按位置归入城市；没有 GPS 的照片可在页面上手动指定城市。只有**有照片的城市**才能进入城市观察。
3. 在全球浏览中，☝️ 伸出食指并左右拨动，地球绕轴惯性旋转。收手不会使其倒转。看到想进入的地点后，用🤏食指和拇指**捏合、分开、再捏合**，进入右侧提示的城市；也可直接点城市按钮。
4. 在**城市观察**中，握拳静止约半秒，再向左或右移动，切换有照片的城市。张开整只手掌并保持约半秒，打开当前城市的照片。🤏双捏合可返回全球；页面也有「查看照片」「返回全球」。
5. 在**照片相册**中，张掌左右摆动翻照片；握拳保持约半秒，返回城市观察。也可使用页面箭头、方向键和 `Esc`。

两次捏合的闭合间隔为 180–1200 毫秒；每次闭合要稳定识别 3 帧，分开要稳定识别 2 帧。模式切换后约有 650–700 毫秒保护期。识别到两只手时会暂停手势，回到单手后等待约 6 帧。调试时打开 `http://127.0.0.1:8000/?debug=1`，按[测试单](GESTURE_TEST.md)依次检查按钮、全球旋转、进城、切城和照片操作。

## 验证与回退

运行 `node tests/album.test.js` 可检查双捏合、食指轴向旋转、握拳切城、张掌开照片、惯性和调试面板逻辑。自动测试通过；真实摄像头下的误识别和手数抖动仍以现场测试结果为准。

停止本地服务后，运行 `git switch photo-open-fix-v9` 可回到今天修正轴向旋转和握拳切城之前的本地版本；运行 `git switch index-pointer-v8` 可回到食指控制的最初版本。照片保存在被 Git 忽略的 `local_photos/`，切换分支不会删除它们。回到当前版本运行 `git switch axis-spin-city-fist-v10`，再用 `python3 server.py` 启动。
